# La Condesa - Clothing Shop

Plataforma web de gestión comercial y control de inventario para la tienda de
ropa **La Condesa** (Maturín, estado Monagas). Catálogo público, apartados en
línea, carrito, pedidos con QR, inventario, reportes y auditoría.

## Contenido del repositorio


Toda la documentación de instalación, configuración, pruebas y producción
está en el [README de la aplicación](La-Condesa-Clothing-Shop/README.md).

## Despliegue

El despliegue se realiza en Render desde la rama `master`, con
`La-Condesa-Clothing-Shop` como directorio raíz del servicio (ver `render.yaml`).
